# Design References

Folder: `design/references/<brand>/DESIGN.md` (MIT, source: github.com/VoltAgent/awesome-design-md, commit in `design/references/SOURCE_COMMIT`).

## How to use
1. List brands: `ls design/references`.
2. Read only the 1 to 3 files that fit the task. Do not load the whole folder.
3. Borrow **principles and patterns** (type scale, spacing rhythm, color roles, component anatomy, motion timing). Never copy a brand's logo, name, exact palette as a whole, or trade dress. PromoVote keeps its own identity.
4. PromoVote's own system lives in the landing page CSS (`web/landing/public/styles.css`): dark base, pink to violet gradient, lime accent, Bricolage Grotesque + Inter. If a project `DESIGN.md` exists at the repo root, it wins over any reference.

## Good matches for PromoVote
* Feeds and creator profiles: `spotify`, `pinterest`, `x.ai`, `playstation`
* Product UI and dashboards (Trailer Test report): `linear.app`, `vercel`, `posthog`, `stripe`
* Bold marketing pages: `framer`, `raycast`, `nike`
* Onboarding and forms: `airbnb`, `cal`, `notion`
