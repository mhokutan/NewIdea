Write to them directly with the Cloudflare D1 tool (d1_database_query); there is no API endpoint and no key. Touch ONLY these two tables, never any other table in promovote-db. Table office_agents: id (text, 2 to 40 characters, a to z, 0 to 9 and -, for example ceo, hauling-dev, empire-desktop, robo-works), role (text up to 60, the shown name, for example "Hauling Geliştirici"), status (one of working, idle, waiting_owner, blocked, offline), last_action (text up to 160 or NULL), needs_owner (text up to 300 or NULL; the yes you need from the founder), updated_at (ISO time UTC). Table office_notes (for later: notes from the founder): id (text, a UUID), created_at (ISO time), text (up to 1000), status (new, read or answered), answer (text up to 2000 or NULL). Never write personal data (e-mails, player or customer names, keys, secrets). Set needs_owner back to NULL once the founder answered. The page refreshes every 30 seconds.
