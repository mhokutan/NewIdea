# OnlyAds (working name)

> The social media of ads.

A platform where ads are the content. Advertisers are creators with profiles, followers and rankings. Users are curators who discover, vote and get recognized for finding things first.

**Phase 1 focus:** indie game trailers. Developers get a "Trailer Test" report (where viewers dropped, which version won, how many wishlist clicks). Players get a daily discovery feed, predictions and weekly rankings.
