Safe by design

  • Every upload goes through the same review as promos posted in the app. Nothing skips moderation.
  • Keys are scoped (upload, read stats) and can be revoked at any time. Daily limits per key.
  • "Made with AI" is a required field. Undisclosed AI content can be reported and removed.
  • The API never buys reach: no feed position, no chart position, no votes. Same fair rotation for everyone.
